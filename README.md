# Tamil Wedding Invitation Website

A mobile-first, single-page wedding invitation inspired by modern cinematic wedding websites.

## Quick start

Open `index.html` directly in a browser, or deploy the folder to Cloudflare Pages / Netlify / Vercel.

## Customize

- Edit names, dates, venue and map link in `index.html`.
- Edit `WEDDING_DATE` in `script.js` for the countdown.
- Add your own photos by replacing the CSS gradients in `.p1` through `.p6` with `background-image: url(...)`.
- Add `music.mp3` and uncomment `music.src='music.mp3';` in `script.js`.
- For a real RSVP backend, connect the form to Formspree, Google Sheets, Supabase, Firebase, or your own API.

## Deployment

Cloudflare Pages can deploy this as a static site. Upload the folder contents or connect a Git repository.
